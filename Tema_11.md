## Лабораторная работа №2
### Класс итератор с гибкой настройкой и удобными применением.

**Код:**

```python
class CountDown:
    def __init__(self, start):
        self.count = start + 1

    def __iter__(self):
        return self

    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count

if __name__ == '__main__':
    counter = CountDown(5)
    for i in counter:
        print(i)
```

**Результат:**

![т11л_2](т11л_pic/т11л_2.png)

**Выводы:** Реализован класс-итератор CountDown с методами iter и next для обратного отсчета.

## Лабораторная работа №5
### Такой же счетчик, как и в первом задании, только это генератор и использует yield.

**Код:**

```python
def countdown(count):
    while count >= 0:
        yield count
        count -= 1

if __name__ == '__main__':
    counter = countdown(5)
    for i in counter:
        print(i)
```

**Результат:**

![т11л_5](т11л_pic/т11л_5.png)

**Выводы:** Реализован генератор с использованием yield для обратного отсчета, обеспечивающий эффективное использование памяти.

## Самостоятельная работа №1  
### Реализовать программу, которая считает числа Фибоначчи при помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield.

**Код:**

```python
def fib(n):
    a, b = 1, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

n = 200
fibonacci = list(fib(n))[-1]
print(fibonacci)
```

**Результат:**

![т11с_1](т11с_pic/т11с_1.png)

**Выводы:** Создан генератор чисел Фибоначчи с использованием yield для эффективного вычисления больших последовательностей.

## Самостоятельная работа №2
### К коду предыдущей задачи добавьте запоминание каждого числа Фибоначчи в файл “fib.txt”, при этом каждое число должно находиться на отдельной строчке.

**Код:**

```python
def fib(n):
    a, b = 1, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

with open("fib.txt", "w") as file:
    for i, num in enumerate(fib(200), 1):
        file.write(f"{num}\n")
```
